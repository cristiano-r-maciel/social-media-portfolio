# Cristiano Maciel — Social Media & Digital Marketing Portfolio

A self-contained, production-ready **static website**. No Codex, Node.js build, paid hosting, databases, third-party APIs, or environment variables required.

## Local preview (Windows)

Extract this ZIP fully (do not open index.html from inside the compressed ZIP), then double-click `index.html`. Image, CSS, JavaScript, and favicon paths are relative so they work in both local `file://` preview and Vercel hosting.

## Deploy on Vercel (recommended: GitHub import)

1. Unzip this folder.
2. Create a **new GitHub repository** (e.g. `cristiano-social-media-portfolio`).
3. In GitHub, choose **Add file → Upload files**, drag the **contents of this folder** (including `index.html`, `styles.css`, `script.js`, `assets/` and `vercel.json`) into the repository and commit. Keep the files at the repository root.
4. Open https://vercel.com/new and import the repository.
5. Select framework preset **Other**. Leave **Build Command** empty and leave **Output Directory** empty (root). Deploy.
6. After deployment, open the generated `*.vercel.app` domain and test links/mobile layout.

Alternative, if you have Vercel CLI installed and are logged in, open a terminal **inside this folder** and run: `vercel --prod`.

If GitHub's upload interface does not accept a whole folder, upload each root file and the six image files into a GitHub `assets` directory, or use Git locally.

## Update the portfolio

- Headings, links, captions, metrics: `index.html`
- Colors, layouts, animations: `styles.css`
- Gallery/modal behavior: `script.js`
- Portfolio images: `assets/*.webp`
